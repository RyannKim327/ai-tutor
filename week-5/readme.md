# Understanding Number Patterns

In this lesson, we will learn about number patterns, which are sequences of numbers that follow a specific rule. Think of number patterns like a dance routine—each dancer (number) has a place to be based on a specific order or rhythm (rule).

## What are Number Patterns?
Number patterns can be created by adding or subtracting a certain number repeatedly. For example, if we start with the number 2 and keep adding 3, we will get the pattern: 2, 5, 8, 11, 14...

## Real-Life Analogy
Imagine you are stacking blocks. If you start with 1 block and every time add 2 more blocks, your stack will grow as follows:
- Start: 1 block
- After 1 step: 1 + 2 = 3 blocks
- After 2 steps: 3 + 2 = 5 blocks
- After 3 steps: 5 + 2 = 7 blocks

You can see how the number of blocks increases in a predictable way!

## How to Think About the Challenge
1. First, think of a starting number (like the first block in your stack).
2. Decide if you want to add or subtract a number (like how many blocks you add each time).
3. Determine how many times you want to repeat this process.

By following these steps, you will create a number pattern.
